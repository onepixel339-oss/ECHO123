# Retention pulse (one week later) / نبضة العودة (بعد أسبوع)

> Send one week after the session, through the same channel. Two questions only — nothing else is collected. A non-reply is recorded as a non-reply, never guessed.

---

## English

Hi again! One week ago you tried ECHO. Two quick questions:

1. Did you open ECHO again during the week? (Yes, a few times / Yes, once / No — I kept thinking about it / No)
2. If yes — what did you open it for? If no — what would have made you open it?

That's it — thank you again!

## العربية

أهلاً تاني! من أسبوع جربت ECHO. سؤالين سريعين:

1. فتحت ECHO تاني خلال الأسبوع؟ (نعم، كذا مرة / نعم، مرة / لا — بس فكرت فيه / لا)
2. لو نعم — فتحته ليه؟ لو لا — إيه اللي كان يخليك تفتحه؟

كده خلاص — شكراً تاني!
